# Tune Titans MTY TEC 2026

Sitio web de la competencia nacional de grabación estudiantil Tune Titans — 13 y 14 de noviembre de 2026, Campus Monterrey.

Incluye información de categorías, jueces, cronograma, el hackathon de Ableton y cómo participar.

## Desarrollo

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
```

Construido con React + Vite.
